1Flowchart — CI/CD Pipeline

flowchart TD

flowchart TD
    A([Developer Push]) --> B{Code Review}
    B -->|Pass| C[Build & Test]
    B -->|Fail| D[Fix & Re-push]
    D --> A
    C --> E{Tests Pass?}
    E -->|Yes| F[Build Docker Image]
    E -->|No| G[Log & Notify]
    G --> A
    F --> H[Push to Registry]
    H --> I[Deploy to Staging]
    I --> J{Rolling Update}
    J --> K[Health Check]
    K --> L{Healthy?}
    L -->|Yes| M[Route Traffic]
    L -->|No| N[Rollback]
    N --> O((Incident))
    M --> P[Monitor & Alert]
    P --> Q([Production Live])

2Sequence Diagram — Đặt hàng Online

sequenceDiagram

sequenceDiagram
    actor User as Người dùng
    participant App as Web App
    participant Cart as Giỏ hàng
    participant Order as Đơn hàng
    participant Pay as Cổng thanh toán
    participant DB as Database
    participant Email as Email Service

    User->>App: Thêm sản phẩm vào giỏ
    App->>Cart: Lưu giỏ hàng
    Cart-->>App: OK
    User->>App: Thanh toán
    App->>Order: Tạo đơn hàng
    Order->>DB: Lưu đơn hàng (pending)
    DB-->>Order: order_id
    Order->>Pay: Xử lý thanh toán
    Pay-->>Order: success + transaction_id
    Order->>DB: Cập nhật trạng thái (paid)
    DB-->>Order: OK
    Order->>Email: Gửi xác nhận
    Email-->>User: Email xác nhận
    Pay-->>App: Redirect thành công
    App-->>User: Hiển thị đơn hàng #order_id

3Class Diagram — E-Commerce

classDiagram

classDiagram
    class User {
        +UUID id
        +String name
        +String email
        +String password_hash
        +register()
        +login()
        +getOrders() List~Order~
    }

    class Product {
        +UUID id
        +String name
        +String description
        +Float price
        +Int stock
        +updateStock(qty)
    }

    class Category {
        +UUID id
        +String name
        +String slug
        +getProducts() List~Product~
    }

    class Cart {
        +UUID id
        +addItem(product, qty)
        +removeItem(product)
        +checkout() Order
    }

    class Order {
        +UUID id
        +DateTime created_at
        +String status
        +Float total
        +pay()
        +cancel()
        +ship()
    }

    class OrderItem {
        +UUID id
        +Int quantity
        +Float price
    }

    class Payment {
        +UUID id
        +String method
        +Float amount
        +String transaction_id
        +String status
        +process()
        +refund()
    }

    User "1" --> "*" Order : places
    Order "1" --> "*" OrderItem : contains
    Product "1" --> "*" OrderItem : line item
    Category "1" --> "*" Product : categorizes
    User "1" --> "1" Cart : owns
    Cart "*" --> "*" Product : holds
    Order "1" --> "1" Payment : has

4State Diagram — Lifecycle Đơn hàng

stateDiagram-v2

stateDiagram-v2
    [*] --> Pending : Tạo đơn hàng
    Pending --> Confirmed : Xác nhận
    Pending --> Cancelled : Huỷ (chưa thanh toán)

    Confirmed --> Paid : Thanh toán thành công
    Confirmed --> Cancelled : Lỗi thanh toán

    Paid --> Processing : Xử lý kho
    Processing --> Shipped : Giao cho vận chuyển
    Processing --> OutOfStock : Hết hàng

    OutOfStock --> Processing : Nh
    OutOfStock --> Refunding : Huỷ + hoàn tiền

    Shipped --> InTransit : Đang vận chuyển
    InTransit --> Delivered : Giao thành công
    InTransit --> DeliveryFailed : Giao thất bại

    DeliveryFailed --> InTransit : Giao lại
    DeliveryFailed --> Refunding : Huỷ + hoàn tiền

    Delivered --> Completed : Hoàn tất
    Completed --> Returning : Yêu cầu trả hàng
    Returning --> Refunding : Xác nhận trả
    Refunding --> Ref hoàn tiền
    Refunded --> [*]

    Cancelled --> [*]
    Refunded --> [*]
